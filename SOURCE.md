# Source

The plugin originated in `yeemio/owlrunkit` under `integrations/dsh/`.
This repository is the independent distribution of that adapter.
The bundled skill in `assets/` comes from
`yeemio/owlrunkit/integrations/codex/skills/owlcoda-runkit` at version 0.24.1.
Both adapter and skill are MIT-0; the separate OwlRunKit CLI is not included.
